# Privacy Policy / プライバシーポリシー — "ThreadsのAPIにアクセス" (Claude Code速報 自動投稿・分析ツール)

_Last updated: 2026-09-21_

## English

**Operator.** This application ("the App", Meta app name: "ThreadsのAPIにアクセス") is a personal, non-commercial tool operated by the owner of the Threads account **@claudecode_news** (an individual based in Japan). It is not offered to the public; the only user is the operator's own Threads account.

**What the App does.** The App (1) publishes posts to the operator's own Threads account on a schedule, (2) reads performance insights, replies and mentions of the operator's own posts to produce a weekly analytics report, and (3) uses Threads keyword search and public profile lookup to observe public posts on topics related to AI news, in order to improve the operator's own content strategy.

**Data we access.** Through the Threads API we access: the operator's profile (id, username), the operator's posts and their insights (views, likes, replies, reposts, quotes, follower counts and aggregated follower demographics), replies and mentions addressed to the operator's posts, and public posts/profiles returned by keyword search or profile lookup (post id, text, username, permalink, timestamp, public profile fields).

**How we use it.** Only to generate the operator's own reports and content. We do not sell, share, rent or transfer any data to third parties. We do not use the data for advertising, for building user profiles, or for any purpose other than the operator's own content analysis.

**Storage and retention.** Data is stored locally on the operator's own computer in Japan. Weekly reports keep aggregated numbers and short excerpts (first line of a post, reply text up to 80 characters, username) for up to 8 weeks for trend comparison, after which they are no longer used. Access tokens are stored in a local file readable only by the operator's user account and are never published.

**Third parties.** The App uses the Threads API (Meta Platforms, Inc.). Generated content may be processed by Anthropic's Claude API for text generation and analysis; no Threads user data other than public post text/usernames included in reports is sent for that purpose. No analytics, advertising or tracking services are used.

**Data deletion.** Any Threads user may request deletion of any data about them held by the App (for example a reply excerpt or a public post excerpt in a report) by contacting us (see below). Requests are honored within 7 days. Revoking the App's access from Threads (Settings → Account → Apps and websites) immediately invalidates our access token; on receiving the uninstall/deletion callback we delete stored data related to the requesting account.

**Contact.** Direct message to @claudecode_news on Threads, or open an issue on this GitHub repository (github.com/claudecode-news/cards).

**Changes.** We will update this page when the App's behavior changes.

## 日本語

**運営者** 本アプリ（Metaアプリ名「ThreadsのAPIにアクセス」）は、Threadsアカウント **@claudecode_news** の運営者（日本在住の個人）が自分のために使う非営利ツールです。一般には提供しておらず、利用者は運営者本人のアカウントだけです。

**アプリがすること** (1) 運営者自身のThreadsアカウントへ予約投稿する、(2) 自分の投稿のインサイト・返信・メンションを読んで週次の分析レポートを作る、(3) AIニュース関連の公開投稿をキーワード検索・公開プロフィール参照で観測し、自分の投稿方針の改善に使う。

**取得するデータ** 運営者のプロフィール（id・ユーザー名）、運営者の投稿とそのインサイト（閲覧数・いいね・返信・再投稿・引用・フォロワー数・集計されたフォロワー属性）、運営者の投稿への返信とメンション、キーワード検索・プロフィール参照で返る公開投稿と公開プロフィール（投稿id・本文・ユーザー名・URL・日時・公開プロフィール項目）。

**利用目的** 運営者自身のレポートと投稿の作成のみ。第三者への販売・共有・貸与・譲渡はしません。広告目的・利用者プロファイリングにも使いません。

**保存と保持期間** データは運営者の日本国内のコンピュータにローカル保存します。週次レポートには集計値と短い抜粋（投稿の1行目・80字までの返信・ユーザー名）を傾向比較のため最長8週間残し、その後は使いません。アクセストークンは運営者のユーザーだけが読めるローカルファイルに保存し、公開しません。

**第三者サービス** Threads API（Meta Platforms, Inc.）を使用します。生成と分析にAnthropicのClaude APIを使うことがありますが、レポートに含まれる公開投稿の本文・ユーザー名以外のThreads利用者データは送りません。アクセス解析・広告・トラッキングのサービスは使いません。

**データ削除** Threadsの利用者はどなたでも、本アプリが保持する自分に関するデータ（レポート内の返信抜粋・公開投稿抜粋など）の削除を下記連絡先へ依頼できます。7日以内に対応します。Threadsの設定（アカウント → アプリとウェブサイト）から本アプリの連携を解除すると、アクセストークンは即時無効になり、アンインストール／削除コールバックの受信をもって当該アカウントに関する保存データを削除します。

**連絡先** Threadsの @claudecode_news へのDM、または本GitHubリポジトリ（github.com/claudecode-news/cards）のIssue。

**変更** アプリの挙動が変わった際は本ページを更新します。
